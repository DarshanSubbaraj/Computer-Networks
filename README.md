## TCP Throughput Analysis

This folder contains the complete analysis and resources for the TCP Throughput Analysis experiment.

### Contents

* **Graphs/** https://github.com/DarshanSubbaraj/Computer-Networks/tree/main/Graphs
  Visualizations generated from the throughput and RTT analysis, including throughput trends, RTT stability, CDFs, and comparison plots.

* **CN.ipynb** https://github.com/DarshanSubbaraj/Computer-Networks/blob/main/CN.ipynb
  Jupyter Notebook containing the Scapy-based Python code used for parsing PCAP files, extracting TCP metrics, and generating graphs.

* **Pcap/** https://github.com/DarshanSubbaraj/Computer-Networks/tree/main/Pcap
  Raw packet capture (`.pcapng`) files used as input for the throughput analysis.

### Objective

Analyze TCP traffic characteristics such as:

* Average Throughput
* Instantaneous Throughput
* Round Trip Time (RTT)
* Packet Rate
* Throughput Distribution
* Comparative Analysis across Different Traffic Conditions
